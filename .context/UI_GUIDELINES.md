# UI Guidelines (Glassmorphism AAA)

## Core Principles
- **Glass Effect**: `backdrop-filter: blur(12px)` + `background: rgba(255, 255, 255, 0.05)`.
- **Borders**: 1px solid `rgba(255, 255, 255, 0.1)`.
- **Typography**: Inter / Roboto. Weights: 300 (Light), 400 (Regular), 600 (Semi-Bold).
- **Grid**: 8pt grid system.
- **Colors**:
  - Primary: `#00E0FF` (Neon Cyan)
  - Background: `#0A0A0A` (Deep Space)
  - Error: `#FF3333`
  - Success: `#00FF99`

## Validation
All UI components must be checked via Browser Subagent to ensure "Pixel-Perfect" alignment with these rules.
