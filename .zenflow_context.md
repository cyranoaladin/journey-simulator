# 🧠 ZENFLOW MASTER CONTEXT - Money Factory AI (S2.4)

## 1. Identité & Stack
- **Projet :** Monorepo Web3 + AI (Money Factory AI)
- **Backend :** Node.js v18.19.1 | Express | Mongoose v8
- **Frontend :** Vite | React | TypeScript
- **Base de données :** MongoDB (Dossier `data/` local - NE PAS TOUCHER)

## 2. Règles d'Or (CRITIQUES)
- **PORT BACKEND :** Toujours **3001** (Port 3000 est corrompu).
- **PORT FRONTEND :** 5173
- **VERSION NODE :** Strictement **v18.x**. Pas de Node 20+.
- **GIT :** Toujours utiliser `git commit --no-verify` (Husky est cassé).

## 3. Architecture Agents
- **Orchestrateur :** `backend/services/EvaluationService.js`
- **Validation :** `backend/controllers/MissionController.js`
- **Endpoint S2.4 :** `POST /api/missions/submit`

## 4. Commandes de Survie
- **Start :** `nohup env PORT=3001 node backend/server.js > backend.log 2>&1 &`
- **Stop :** `pkill -f "node backend/server.js"`
- **Test :** `curl -X POST http://localhost:3001/api/missions/submit ...`
