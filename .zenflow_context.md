# 🧠 ZENFLOW MASTER CONTEXT - Money Factory AI (S2.4)

## 1. Identité & Stack
- **Projet :** Monorepo Web3 + AI (Money Factory AI)
- **Backend :** Node.js v18.19.1 | Express
- **Base de données :** **PostgreSQL (via Prisma ORM)** + **Redis** (Caching).
- **INTERDICTION STRICTE :** MongoDB / Mongoose sont BANNIS. Tout code contenant "mongoose" doit être refactorisé ou supprimé.
- **Frontend :** Vite | React | TypeScript

## 2. Règles d'Or
- **PORT BACKEND :** 3001 (Strict).
- **GIT :** `git commit --no-verify`.
- **DATA SOURCE :**

  - État Utilisateur (User State) : **PostgreSQL**.
