# Phase 4 — Orchestration Entrypoints (Repo-Driven)

## HTTP Endpoints

### Agent Routes (mf-back/routes/agent-routes.js)

```
GET  /api/agent/runs - Get agent runs (protected)
GET  /api/agent/runs/:id - Get agent run details (protected)
GET  /api/agent/logs - Get agent logs
```

### Orchestration Gate (mf-back/routes/orchestration-gate.js)

```
POST /api/orchestration/gate/:gateId/review - Review orchestration gate
```

## Orchestration Components

### Main Orchestrator
- **mf-back/orchestration/zynoOrchestrator.js**
  - Main Zyno orchestration logic
  - Agent invocation
  - Timeline tracking

### Intent Routing
- **mf-back/orchestration/intentRouter.js**
  - Routes user intent to appropriate agent
  - Priority-based selection
  - Collision resolution

### Agent Registry
- **mf-back/orchestration/agentsRegistry.js**
  - Agent registration
  - Agent metadata
  - Agent capabilities

### Agent Protocol
- **mf-back/orchestration/agentProtocol.js**
  - Agent communication protocol
  - I/O contracts
  - Error handling

## Controllers

### Agent Run Controller
- **mf-back/controllers/agent-run-controller.js**
  - `getAgentRuns()` - List agent runs with filters
  - `getAgentRunDetails()` - Get specific agent run details

## Models

### Agent Run Model
- **mf-back/models/agent-run.js**
  - Schema: journeyId, stepId, agentName, status, duration, etc.
  - Tracks agent execution history

## Utilities

### Agent Idempotence
- **mf-back/utils/agent-idempotence.js**
  - `findOrCreateAgentRun()` - Ensures idempotent agent execution

### LLM Logger
- **mf-back/utils/llmLogger.js**
  - Structured logging for LLM/Agent interactions
  - Tracks: userId, journeyId, agent, duration, tokens, success/failure

### AEPO/AECO
- **mf-back/utils/aepoAeco.js**
  - AI-Enhanced Pathway Orchestration (single-user)
  - AI-Enhanced Cohort Orchestration (multi-user)
  - Zyno-driven orchestration

## Frontend Integration

### API Calls (journey-simulator/src)
- Frontend makes calls to `/api/agent/*` endpoints
- Orchestration triggered via journey progression
- Real-time agent status updates
