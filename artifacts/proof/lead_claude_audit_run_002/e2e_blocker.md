## Minimal Surgical Fix

**File:** `journey-simulator/tests/e2e/fixtures/realModeTest.ts`  
**Line:** 64-71

**Current (broken):**
```typescript
export const test = base.extend<Fixtures>({
  authHeaders: async ({}, use) => {
    const { accessToken } = getStorageState();
    await use({
      Authorization: `Bearer ${accessToken}`,
      'x-run-mode': RUN_MODE,
    });
  },
```

**Issue:** Empty object pattern `{}` triggers Playwright's fixture type validation error.

**Fix Option A (recommended):** Use proper unused parameter convention
```typescript
export const test = base.extend<Fixtures>({
  authHeaders: async ({ }, use) => {  // space between braces
    const { accessToken } = getStorageState();
    await use({
      Authorization: `Bearer ${accessToken}`,
      'x-run-mode': RUN_MODE,
    });
  },
```

**Fix Option B:** Disable the lint rule for this fixture
```typescript
export const test = base.extend<Fixtures>({
  // eslint-disable-next-line no-empty-pattern

    const { accessToken } = getStorageState();
    await use({
      Authorization: `Bearer ${accessToken}`,
      'x-run-mode': RUN_MODE,
    });
  },
```

```typescript
export const test = base.extend<Fixtures>({
```
