### MINIMAL NEXT FIX

In `global-setup.ts`, replace:
```typescript
await page.goto(baseURL);
await page.evaluate(() => { localStorage.setItem('accessToken', token); });
await context.storageState({ path });
```

With:
```typescript
await page.addInitScript(({ token, zustandState }) => {
  localStorage.setItem('accessToken', token);
  localStorage.setItem('mfai-journey-storage', JSON.stringify(zustandState));
}, { token: authData.token, zustandState: { state: { runMode: 'real', ... }, version: 0 } });

await page.goto(baseURL);
await context.storageState({ path });
```

This ensures storageState captures the seeded localStorage, not empty initial state.
