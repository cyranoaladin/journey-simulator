# Log-Sleuth Skill

## Competencies
- **Observability Stack**: Interprets logs from `mf-back` and `journey-simulator`.
- **Artifact Intelligence**: Analyzes `artifacts/proof/` and `playwright_report.json` to pinpoint visual or functional regressions.
- **Post-Mortem Engine**: Generates root-cause analysis reports for system failures.

## Application
- Use for debugging E2E test failures and platform crashes.
