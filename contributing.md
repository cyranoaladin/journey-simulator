# 🤝 Contributing to Zyno

## Pré-requis

- Node.js 18+
- MongoDB local ou distant
- Yarn ou npm

## Branches

- `main` : stable
- `dev` : développement actif

## Lancer le projet

```bash
npm install
npm run dev
```

## Lancer les tests

```bash
npm run test
npm run test:coverage
```

## Convention de nommage

- camelCase pour JS
- snake_case pour fichiers
- kebab-case pour branches
