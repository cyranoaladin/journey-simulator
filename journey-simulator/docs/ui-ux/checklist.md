# UI/UX Acceptance Checklist (MVP)

- Modes supportés (metadata.mode): discovery, builder, expert
- Ton pris en compte (metadata.tone): pedagogical / investor_pitch / critical
- Layout 3 colonnes (desktop) et responsive mobile
- AgentActivityFeed visible avec événements récents
- Missions: explication claire + CTA “Comprendre la mission”
- Quiz: feedback immédiat, mode entraînement/certifiant
- Ressources: templates cliquables, flashcards disponibles
- Indicateurs (evaluation_block axes) affichés (barres/jauge)
- Micro-interactions subtiles (apparition blocs, pulsation icônes agents)
- Accessibilité: contrastes, tailles, navigation clavier, hiérarchie titres
- Démo scriptée (DEMO_MODE): parcours pré-rempli, raccourcis de phase
