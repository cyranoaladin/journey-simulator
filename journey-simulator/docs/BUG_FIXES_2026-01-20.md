## ✅ Corrections Appliquées

### Fix #1: Progression des Phases

**Fichier**: `src/store/journeyStore.ts` (lignes 565-595)

**Problème**:
- La séquence `currentSequence` stockait TOUS les steps de TOUTES les phases (13 steps total)
- Quand on terminait les 2 steps de la phase 1, le système ne détectait pas la fin car il restait 11 steps
- Résultat: Pas de modal NFT, pas de progression

**Code Buggy**:
```typescript
currentSequence: fullSequence, // 13 steps (toutes les phases)
stepIndex: phaseStartIndex - 1, // ex: -1 pour phase 1
```

**Code Corrigé**:
```typescript
// STEP 3: Filter only the steps for this phase
const phaseSteps = fullSequence.filter((step) => step.metadata.phase_id === phaseId);

// Validation: Ensure phase has steps
if (phaseSteps.length === 0) {
  console.error(`[Demo] CRITICAL: No steps found for phase ${phaseId}`);
  set({ demoState: { ...get().demoState, isActive: false, status: 'IDLE', currentSequence: [], stepIndex: -1 } });
  return;
}

// STEP 4: Store ONLY phase steps
currentSequence: phaseSteps, // Seulement les steps de cette phase (ex: 2 steps pour phase 1)
stepIndex: -1, // Premier tick nous donne index 0
```

**Impact**:
- ✅ NFT modal s'affiche à la fin de chaque phase
- ✅ Compteur de phase progresse correctement (1/6 → 2/6 → 3/6...)
- ✅ Phases changent automatiquement après validation NFT
