RAG Ingestion Playbook

Procedure to prepare, vectorize, and feed cognitive mesh documents.

1. Data Preparation

Before ingestion, data must be cleaned and structured to maximize retrieval accuracy.

Supported Formats

Markdown (.md), PDF (text-based), JSON (structured logs).

2. Chunking Strategy

Optimal chunk size depends on the embedding model (e.g., OpenAI text-embedding-3-small).

Content Type Chunk Size Overlap
Technical Docs 512 tokens 50 tokens
Code Snippets 256 tokens 20 tokens
General Prose 1024 tokens 100 tokens

3. Vectorization Pipeline

1
Embed: Convert chunks to vectors using the embedding API.
2
Index: Store vectors in Pinecone/Milvus with metadata (source, date, author).
3
Retrieve: Test retrieval with sample queries to verify relevance.
