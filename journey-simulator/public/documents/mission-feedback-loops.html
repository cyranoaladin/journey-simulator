Mission Feedback Loops

AEPO/AECO framework to capture, score, and recycle builder feedback.

AEPO & AECO Overview (Zyno Orchestration)

AEPO (AI-Enhanced Pathway Orchestration) is the Zyno-driven engine that creates and updates a personalized roadmap (milestones, deliverables, and next actions) for an individual builder. AECO (AI-Enhanced Cohort Orchestration) coordinates cohort programs (shared milestones, peer reviews, and group dashboards) for teams, bootcamps, and DAO accelerators.

A/E/P/O Scorecard (signals feeding AEPO)

The following scorecard is used to capture mission signals that feed the AEPO pathway engine. It should not be confused with the AEPO orchestration layer itself.

A - Acquisition

How did the user discover the mission?

E - Engagement

Did they complete the core actions?

P - Proficiency

Did they demonstrate skill mastery?

O - Outcome

What value was created for the ecosystem?

Feedback Collection

Feedback is collected at three distinct touchpoints:

  • In-Mission: Real-time validation of inputs (e.g., code syntax check).
  • Post-Mission: User sentiment survey (NPS) and difficulty rating.
  • Long-term: Retention tracking (did they return for the next mission?).

Closing the Loop

Data collected from these loops is fed back into the Zyno Agent training set. If 30% of users fail a specific step, the agent automatically flags the documentation for review and suggests simplifying the instructions. This creates a self-improving educational protocol.
