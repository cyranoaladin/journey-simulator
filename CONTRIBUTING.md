# Contributing to journey-simulator

Thanks for your interest in contributing! Please follow these guidelines to make the process smooth.

## How to contribute
1. Fork the repository.
2. Create a branch from `main` named `feat/short-description` or `fix/short-description`.
3. Run `npm ci` and make your changes.
4. Run linters, type checks and tests locally.
5. Open a PR describing the change and link any related issue.

## PR checklist
- [ ] The PR has a clear title and description
- [ ] Changes are covered by tests where applicable
- [ ] Linting and type checks pass
- [ ] Commit messages follow conventional commits (recommended)

## Code style
Follow existing code style. Use ESLint and Prettier rules to format and validate code.
