**Solutions**:

1. **Option A - Push avec le bon utilisateur**:
   ```bash

   git config user.name
   git config user.email
   
   # Si nécessaire, changer pour cyranoaladin
   git config user.name "cyranoaladin"

   ```

2. **Option B - Utiliser SSH au lieu de HTTPS**:
   ```bash
   # Changer le remote vers SSH
   git remote set-url origin git@github.com:cyranoaladin/journey-simulator.git
   ```
