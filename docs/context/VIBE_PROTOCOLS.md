# Vibe Coding Protocols (Human-AI Interface)

## Core Philosophy
We do not chat. We execute. Use these "Magic Keywords" to pilot the Swarm.

## Magic Keywords

### 1. "AUDIT_MODE"
**Effect**: Activates `@security-sentinel` exclusively.
**Use Case**: When you want a raw, zero-tolerance security review of a specific file.
**Example**: "AUDIT_MODE check mf-back/routes/auth.js"

### 2. "TURBO_DEPLOY"
**Effect**: Triggers the `/ship-it` workflow immediately, bypassing non-critical discussion.
**Use Case**: When you are 100% confident and just want to push to prod.
**Example**: "TURBO_DEPLOY now."

### 3. "PIXEL_PERFECT"
**Effect**: Activates `@creative-studio` and forces `Browser Subagent` validation against `UI_GUIDELINES.md`.
**Use Case**: For any frontend tweak.
**Example**: "PIXEL_PERFECT fix the bonding curve gradients."

### 4. "DEEP_THINK"
**Effect**: Forces **Gemini 3 Deep Think** model for complex architecture logic.
**Use Case**: Refactoring orchestration or math formulas.

## Interaction Style
- Be direct.
- Reference files with `@`.
- Use `/slash-commands` for workflows.
