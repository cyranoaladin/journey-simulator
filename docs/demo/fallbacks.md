# Fallbacks démo

- DEMO_MODE=true: réponses déterministes (replay), pas de dépendance réseau LLM
- llm=1: forcer un appel live ponctuel si latence acceptable
- KILL_SWITCH=1: désactiver l’exécution on‑chain (devnet instable)
- RPC de secours: basculer SOLANA_RPC_URL vers un endpoint alternatif fiable
- Replays préchauffés: docs/demo_script.md et docs/demo/replays/* (à ajouter si besoin)
